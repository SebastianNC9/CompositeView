# CompositeView

Este tarea es una interfaz web simple que permite navegar entre diferentes secciones como "Inicio", "Suscripciones" y "Perfil". 
Utiliza JavaScript para generar dinámicamente los elementos en la página, como la barra de búsqueda y las tarjetas de video.

## Descripcion

- Mis component view seria las clases "Header", "SearchBar" y "VideoCard"
- Los elementos de la pagina se generan de forma dinamica mediante JavaScript
- Estructura modular con componentes reutilizables

## Archivos principales

- `index.html` → Página principal.
- `styles.css` → Estilos de la página.
- `script.js` → Lógica del proyecto.
- `components/` → Contiene los archivos de los componentes.
